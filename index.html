Encryption: AES‑256‑GCM. Your password is stretched with PBKDF2 (SHA‑256, 600,000 rounds) before it's used as a key. A new random salt and IV are generated for every file.

There's no password recovery. If you forget a password, that file is permanently unreadable — nobody, including this tool, can get it back.

This is a separate, browser-based tool and its file format isn't compatible with the FEAR desktop app.
